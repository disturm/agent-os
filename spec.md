## Проект

Локальный wellness-агент в одном файле. Это НЕ медицинский продукт: агент даёт только рекомендации по питанию, тренировкам, восстановлению и привычкам. Диагнозы, лечение, лекарства — вне зоны ответственности: в таких случаях агент советует обратиться к специалисту.



## Задача

Создай минимальный локальный агент со следующей структурой:

index.ts      — весь оркестратор
profile.md    — профиль пользователя (цели, ограничения, предпочтения) — заполни правдоподобным примером
log.md        — дневник последних дней (еда, сон, тренировки) — заполни примером на 3–4 дня
output.md     — сюда сохраняется финальный план



## Флоу (оркестрация — в коде, не в промпте)

1. Читаем task из аргумента CLI: `npx tsx index.ts "составь план питания на завтра"`.
2. Читаем profile.md и log.md, подставляем в контекст.
3. Health Coach Agent генерирует план.
4. Safety Reviewer Agent проверяет план и возвращает строго JSON: { "verdict": "approve" | "revise" | "needs_human_professional", "score": number (0–10), "issues": string[] }.
5. Если verdict = "revise" — отправляем issues обратно коучу, максимум 3 раунда.
6. Если verdict = "needs_human_professional" — останавливаемся и пишем в консоль, что запрос требует специалиста.
7. Если approve — сохраняем план в output.md и печатаем score.



## Стек

- TypeScript, запуск через tsx
- OpenAI Agents SDK (@openai/agents)
- Провайдер: DeepSeek через OpenAI-compatible API (baseURL и ключ из .env)
- Zod — валидация JSON reviewer-а
- Никаких БД: только markdown-файлы



## Требования к коду

- Один index.ts, до ~150 строк, с короткими комментариями на русском по ключевым шагам.
- Системные промпты обоих агентов — константы прямо в index.ts.
- В системном промпте коуча: роль, формат плана, запрет на медицинские советы.
- В системном промпте ревьюера: критерии проверки (безопасность, реалистичность, соответствие профилю) и требование отвечать только JSON.
- Логируй в консоль каждый раунд: номер, verdict, score, issues.



## Запрещено

- Никакого UI, API, серверов, баз данных.
- Никаких классов, слоёв, папок src/ — один файл.
- Не добавляй tools/function calling — агенты работают только на контексте из файлов.
- Не пиши код «на будущее» и конфиги для несуществующих фич.



## Definition of Done

- `npx tsx index.ts "задача"` проходит полный цикл: генерация → ревью → (ревизия) → output.md.
- Медицинский запрос («подбери мне лекарство от давления») приводит к остановке с verdict needs_human_professional.
- Reviewer JSON валидируется Zod; невалидный JSON = повторный запрос ревьюеру (1 ретрай).
